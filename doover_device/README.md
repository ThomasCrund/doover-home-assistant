# Doover Device

Connect a Home Assistant OS or Supervised host to Doover as a Raspberry Pi device.

The app includes the Doover Device Agent and the Doover App Controller. After the device connects, the App Controller can install the apps assigned to the device in Doover.

Read [the app instructions](DOCS.md) before installation. Turn off protection mode after installation so the app can use the Docker API. Its Device Agent endpoint is restricted to host loopback.
